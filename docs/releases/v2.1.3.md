# Property Details v2.1.3 — Interact Presentation Release

**Released:** 2026-10-09  
**Interact page:** `2186`  
**Paired renderer:** `austinmhorn/property-details-page-composer` (tag `v2.1.3`)

## What shipped

The Composer delivers one HTML document containing Details View and the portfolio Table View. This repository supplies the presentation and interactions from `property_details/property-details.css` and `property_details/property-details.js`.

- Details / Table switching while retaining hash-based property navigation.
- Header chevrons for each registry-approved table column, with ascending/descending sorting, searchable checklists, multiple selected filter values and Apply.
- Multiple column filters combine with AND; values within a column combine with OR.
- Selected filter state marked by **one** highlighted chevron (not a duplicate dot).
- Columns chooser: selected fields saved in local storage, Property always visible, Select All, Reset defaults.
- Search, filtered/sorted CSV export, and clickable normalized website URLs.
- Dropdown dismiss-on-outside-click and Escape.
- **v2.1.3 production hotfix:** scope explicit 18px square checkbox styling to the Columns chooser, overriding Interact's global checkbox skin. This affects appearance only, not visibility or interaction logic.

## Verification and compatibility

- User tested the core Table interactions and CSV export in the portal render preview, then confirmed live production behavior in Interact.
- The original live-page checkbox controls appeared as tall pill-shaped elements due to the Interact host CSS. The v2.1.3 CSS override returned them to the compact checkbox appearance tested in preview.
- Keep Details-only legacy markup safe: the table-specific behavior is feature-detected.
- The composer template and registry visibility rules remain the source of truth. Do not expose hidden/internal columns through dynamic filtering.

## Deployment

- Portal **Pages → Property Details → View Render** loads customization CSS/JS from GitHub `main` via the portal's authenticated asset endpoint.
- Live Interact page `2186` may use a different asset-loading path; confirm the source during future releases before assuming that pulling source updates the live page.
- The publisher in the companion Composer repository updates the saved HTML fragment with `--existing` and preserves Interact metadata without sending notifications.
- Run `node tests/details-contract.test.cjs && node tests/table-contract.test.cjs` before publishing changes.
